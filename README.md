## Student Assignment Planner
The goal of Student Assignment Planner application is helping students to avoid forgetting deadlines.

## Target Users
Students who want to organize assignments, deadlines, and tasks to complete them in time.

## Technology

Python with a terminal interface

## Set up and Run Instructions
1. Go to Github repository page. Click the <> code button. Under HTTPS, click copy URL.
2. Open VS Code(Visual Studio Code). Make sure to install Python 3 and Git on your system (VS Code will prompt you if not).
3. Use the Command Palette to clone. Press Ctrl+Shift+P (Windows / Linux) or Cmd+Shift+P(macOS). Type "Git: Clone" and select it. Paste the     GitHub URL you copied.
4. Choose a local folder. Select the folder where you want the repository saved. VS Code will clone the repository and prompt: "Open the cloned repository?" Click open.
5. (Alternative) You can clone directly via built-in terminal:
git clone https://github.com/charlisabell2-dev/To-Do-List.git
6. Open the cloned To-Do-List folder. Open its terminal and run:
python app1.py
Enter an assignment name, and press Enter. Enters an assignment deadline, and press enter.

## Limitations
- The program diplays only one assignment and deadline for each run.
- The program does not yet save assignments and give reminders and calenders.
- This program is a long-term goal from what currently works.
